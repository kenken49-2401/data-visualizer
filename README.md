# Codex Usage Overlay

Windows の ChatGPT デスクトップ版を使っている間、Codex の **5時間枠・7日間枠の残り割合**を小さなパネルに表示します。黒ベース・青アクセント・角丸の表示です。

## インストール・旧版からの切り替え

1. 旧 ZIP 版が起動中なら、通知領域のアイコンを右クリックして「終了」します。
2. [最新リリース](https://github.com/kenken49-2401/data-visualizer/releases/latest)の `Codex-Usage-Overlay-Setup-<version>.exe` をダウンロードして実行します。
3. インストール後は **Codex Usage Overlay** をスタートメニューやデスクトップから起動します。Node.js のインストール、ソース ZIP、コマンドプロンプトは不要です。
4. スタートメニューでアプリを右クリックして、スタートまたはタスクバーにピン留めできます。

Windows x64 向けです。インストール先はユーザーのフォルダーが標準で、管理者権限を必要としません。電子署名は未設定なので、Windows SmartScreen の警告が出る場合があります。

既存の `%APPDATA%\codex-usage-overlay\settings.json` を引き継ぎます。公式 Codex のログインも同じ Windows ユーザーのものを利用します。ログインが必要な場合はトレイメニューの「ChatGPT アカウントでログイン」を選んで、同じ Plus アカウントでブラウザの認証を完了してください。GitHub へログインする必要はありません。

旧版の ZIP 自動更新からインストーラーへは、**この一度だけ手動で切り替え**ます。ZIP 版の `update.json` は v0.2.1 のまま保持し、別の配布方式を自動で上書きしません。インストーラー版の起動を確認した後は、旧 ZIP フォルダーを削除できます。

## 表示する条件

標準では **ChatGPT デスクトップ版が最前面のときだけ表示**します。ブラウザの ChatGPT と Codex 単独アプリは対象外です。ほかのアプリに切り替えたとき、ChatGPT を最小化・終了したときは隠します。約0.5秒ごとに状態を確認します。ウィンドウ検出が失敗・停止した場合も隠します。トレイと使用量の更新は継続します。

ChatGPT のメニューを Windows のアクセシビリティ情報で検出した間、パネルを隠し、アカウントメニューなどを操作できるようにします。メニューの文字や会話本文を収集せず、メニューの役割と可視状態だけを調べます。**ChatGPT 側がメニューをアクセシビリティ情報として提供しない場合、検出できないことがあります。** この場合はパネルの位置をずらすか、×で一時的に隠してください。

トレイの「ChatGPTが最前面のときだけ表示」を外すと、常時表示もできます。手動で隠した・最小化したパネルを、バックグラウンド更新で勝手に復帰させません。「表示する」を選んでも標準の表示条件は維持します。

## 残量・使用量の自動更新

5時間枠・7日間枠をそれぞれ独立して色分けします。

| 残り割合 | 棒の色 |
| --- | --- |
| 30%より多い | 青 |
| 10%より多く、30%以下 | 黄 |
| 10%以下 | 赤 |

0%では棒の幅も0になります。残量が回復したら色も元に戻ります。標準は **1分ごと**の更新です。設定で1・2・3・5分を選べます。「更新」で即時取得し、スリープからの復帰でも取得します。トレイアイコンにカーソルを合わせても残量を見られます。

OpenAI の公式 [Codex app-server](https://github.com/openai/codex/tree/main/codex-rs/app-server) に、同梱したネイティブ Codex 実行ファイルを通じて接続します。`account/rateLimits/read` が返す Codex の期間300分・10080分の値を使い、残り割合は `max(0, 100 − usedPercent)` です。回数やトークン数は推測しません。取得失敗時は前回値と明示し、認証喪失・アカウント変更時は消します。リセット時刻を過ぎただけで100%には戻しません。

## 位置・大きさ・非表示

⚙ またはトレイアイコンの右クリックで設定します。

- ヘッダーをドラッグして自由な位置に移動できます。画面左下、ChatGPT左下への追従、自由位置を選び、10px単位でも調整できます。
- 表示先のモニターを選べます。モニターを外したら到達可能な位置へ戻します。
- 最小252×178、コンパクト292×204（標準）、ゆったり332×224の3サイズです。
- ×は通知領域へ隠し、−はタスクバーへ最小化します。トレイのクリック・「表示する」、またはタスクバーから復帰できます。
- 完全終了はトレイの「終了」です。

位置・サイズ・更新間隔などを保存します。アンインストールしても設定とログイン情報は消しません。

## プログラムの自動更新

インストーラー版は **起動時と30分ごと**に、この公開GitHubリポジトリの正式リリースを確認します。更新を自動ダウンロードし、準備ができると「再起動」を表示します。そのボタンから適用でき、通常のアプリ終了時にもインストールします。作業中に突然再起動はしません。次の起動で新しい版を使えます。

メニューから手動で確認したり、自動確認をオフにしたりできます。すでに取得済みの更新は終了時の適用対象です。更新ファイルのチェックサムを検証します。通信・ダウンロードに失敗した場合は現行版を使います。NSIS更新は旧ZIPランチャーの自動ロールバックとは異なります。インストール後に問題がある場合はGitHubの前のリリースを再インストールできます。設定は引き継ぎます。

公開するのはプログラムとインストーラーだけです。使用量・会話・認証情報をGitHubへアップロードしません。トークンは公式Codexに管理を任せ、このアプリは認証ファイルを読んで独自にコピーしません。

## 開発・配信

Node.js 24とWindows x64を使用します。

```sh
npm ci
npm run install:electron
npm test
npm run demo
npm run smoke
npm run dist:win
npm run smoke:packaged
```

開発時の `npm start` はZIPランチャー経由です。配布版はElectron本体、公式Codex、必要な依存関係を同梱します。Codexのネイティブ実行ファイルは `app.asar.unpacked` に展開します。配布版は `electron-updater`、ソース版は旧ランチャー方式の更新を使います。実アカウントの取得は `npm run probe` で別途確認します。デモ・スモークでは架空の値を明記し、OpenAIへの認証・通信をしません。

Windows Actionsで、単体テスト、全サイズと警告色の画面テスト、旧ランチャーのステージ更新・ロールバック、NSISビルド、パッケージ起動、サイレントインストール、スタートメニュー登録、同梱Codexの起動、GUI実行ファイルの種別、アンインストールを検証します。mainへのpushでは検証成果物を保存します。正式配布はpackage.jsonとlockの版を上げ、`RELEASE-NOTES.md`を更新し、対応する `v<version>` タグをpushします。検証成功後にGitHub Releasesへインストーラー・blockmap・latest.ymlをまとめてアップロードします。

```sh
npm run smoke -- --launcher
npm run smoke -- --staged-update
npm run smoke -- --rollback-update
```

Linuxの画面がない環境では、スモークがXorg dummyで一時画面を用意します。このクラウドの制約では、通信しないデモ検証に限って `--cloud-no-sandbox` を使います。通常起動・Windows配布版のサンドボックスは無効化しません。実際のChatGPTメニュー・DPI・タスクバーのピン留め操作・二つの正式リリース間の更新は、ユーザーのWindowsデスクトップでの追加確認が必要です。
