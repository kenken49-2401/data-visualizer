スリープ中も記録する

無料の GitHub Actions が約10分おきに取得し、PCの復帰後に24時間グラフへ取り込みます。

定期実行は遅れる・省略されることがあります。記録できなかった時間は空白として表示します。公開リポジトリの標準ランナーを使用します。

1. 記録用の鍵を作る

この鍵をGitHubのシークレットに登録します。アプリには履歴を読む鍵だけをWindowsで保護して保存します。

鍵を選択してコピーし、安全な場所にも保管してください。チャットや公開ファイルには貼らないでください。

別のPC・再インストール時：既存の鍵で接続

2. GitHub に登録する

下のボタンから New repository secret を選び、Name を USAGE_RECORDING_KEY、Secret を上の鍵にして保存します。

3. クラウド側でログインする

Actions画面で Run workflow を選び、mode を login にして実行します。準備ができると下にコードが表示されます。

認証コード：

このPCと同じ ChatGPT Plus アカウントでログインし、クラウド側のCodexを認証してください。PCの認証ファイルを転送する必要はありません。

4. 自動記録を確認する

以降はPCを閉じていても記録されます。認証が切れた場合は手順3を再実行してください。定期実行が無効化された場合も Actions で再開してください。

同期解除ではクラウドの記録は止まりません。完全に停止するには GitHub のシークレットを削除し、ワークフローを Disable workflow にしてください。OpenAIの認証も必要に応じて取り消してください。
